## 1. TUI 是什么？

Fuxi TUI（终端用户界面）是运行在终端中的**统一仪表盘**。以前你需要记住并输入六七个不同的命令来注册论文、下载数据、生成配置、运行管线、查看结果——现在只需用键盘在一个统一界面中导航即可。

把它理解为你的单细胞分析项目的"控制中心"。

**替代了什么：**

| 旧方式（多个命令） | 新方式（TUI） |
|---|---|
| `python -m core.paper.registry status --gse GSE123456` | 注册表界面 → 搜索或点击 |
| `python core/geo_downloader.py --gse GSE123456` | 数据管理 → 下载标签页 |
| `python core/preprocess/preprocessor.py --gse GSE123456` | 数据管理 → 预处理标签页 |
| `python core/run_pipeline.py --modality rna --config ...` | 管线界面 → 选择步骤 → 点击运行 |
| 手动打开 CSV 文件检查结果 | 结果界面 → 点击查看解析后的表格 |

## 2. 启动 TUI

```bash
# 先激活虚拟环境
source .venv/bin/activate

# 启动 TUI
python -m core.tui
```

TUI 会全屏打开。按 `Ctrl+Q` 随时退出。

---

## 3. 界面概览

TUI 有 **6 个界面**，可通过键盘快捷键和首页的快捷按钮访问：

| 界面 | 功能 | 快捷键 |
|------|------|--------|
| 🏠 首页 | 起始页；选择模态、快捷按钮 | `Ctrl+H` |
| 📋 注册表 | 浏览/搜索已注册的论文和数据集 | `Ctrl+R` |
| ⚙️ 管线 | 选择并运行分析步骤 | `Ctrl+P` |
| 📊 结果 | 查看 QC 报告、标记基因、富集结果 | `Ctrl+E` |
| 📦 数据管理 | 注册论文、下载 GEO 数据、生成配置 | `Ctrl+D` |
| 📝 配置编辑 | 用表单式编辑器编辑 YAML 配置文件 | `Ctrl+C` |

---

## 4. 首页

启动后看到的第一个页面。显示：

- **模态选择器**（rna / atac / spatial）——切换后影响整个 TUI 中显示的步骤和配置
- **快捷按钮**——直接跳转到注册表、管线或结果

---

## 5. 注册表浏览器

显示 Fuxi 中已注册的所有论文和数据集。

- **搜索**：输入 GSE ID、PMID 或关键词过滤
- **状态徽章**：每个数据集的彩色状态标识（🟢 已下载，🔵 管线完成，⚪ 未下载）
- **点击行**查看详细信息（标题、作者、物种、模态、关联论文）

---

## 6. 管线运行器

这是**核心工作界面**：

1. 顶部**选择模态**（rna/atac/spatial）
2. **查看步骤状态**：已完成的步骤显示绿色对勾
3. **勾选要运行的步骤**
4. 点击**"运行所选步骤"**——管线按序执行
5. **观察进度**：进度条显示每步状态，日志面板实时滚动输出
6. 随时点击**停止**按钮中断运行

**依赖提示**：如果你勾选了步骤 5 但尚未运行步骤 3，会显示警告标识指出缺失的前置步骤。

---

## 7. 配置编辑器

无需接触原始 YAML 即可编辑配置文件：

- **加载配置**：点击"加载 YAML"从列表中选择配置文件
- **表单字段**：每个参数显示为表单组件（数字输入、开关、下拉菜单）——无需学习 YAML 语法
- **分区**：参数按功能分组（QC、HVG、聚类等）
- **保存**：点击"保存 YAML"写入更改
- **编辑器打开**：高级用户可点击"外部编辑器打开"启动 vim/nano

---

## 8. 结果查看器

管线步骤完成后，查看解析后的结果：

- **QC 报告**：过滤前后的细胞数、基因中位数等
- **标记基因**：每群细胞的标记基因表格（可搜索、可排序）
- **富集分析**：通路富集结果按显著性排序
- **选择配置**：选择查看哪个项目的结果

---

## 9. 数据管理

三个标签页用于项目设置：

| 标签页 | 用途 |
|--------|------|
| **注册** | 通过 PMID 添加论文 → 自动从 NCBI 拉取元数据 |
| **下载** | 输入 GSE ID → 列出文件 → 选择并下载（含进度条） |
| **预处理** | 检测数据格式 → 生成配置文件 → 准备运行管线 |

## 11. 使用技巧

- **快捷按钮**：首页的三个按钮是用鼠标跳转到注册表、管线、结果的最快方式
- **鼠标可用**：所有按钮和选择器都可以点击，但键盘更高效
- **恢复运行兼容 TUI**：如果在 TUI 中停止管线运行，可以用 CLI 的 `--resume` 接着跑——TUI 和 CLI 共享同一套检查点系统
- **配置校验**：表单编辑器会阻止无效值（如负数细胞数）
